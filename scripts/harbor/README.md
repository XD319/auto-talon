# Terminal-Bench 2.1 diagnostic subset

This is a **10-task diagnostic subset**, not an official full-benchmark score. The two paid arms are product defaults (`governed`) and the nine-switch **comprehensive ablation**. Both use Alibaba Cloud Beijing `qwen3.7-flash`, 20 iterations, one attempt, and Harbor's official verifier. Scores must never determine task selection.

## Before any paid run

1. Start Docker Desktop and verify `docker info` succeeds. Harbor 0.23.0 is installed locally under `eval-artifacts/harbor/python` and the runner can use it without a global install.
2. Use the reviewed, immutable `eval-artifacts/harbor/subset-lock-qwen-v2.json`: it pins Harbor's Terminal-Bench 2.1 dataset version `6`, its metadata hash, and the **same ten CPU-only task IDs** as `subset-lock-qwen-v1.json`. v1 stays as the unused 2026-09-25 lock at ¥6.7489/USD. v2 exists only because the 2026-10-14 Bank of China middle rate changed before any paid trial. Do not reselect tasks based on results. To inspect or regenerate a future lock, use `python scripts/harbor/lock_subset.py <official-dataset-directory> <version> <new-output.json> [ten-IDs]`; the script refuses to overwrite a lock.
3. Verify [Qwen3.7-Flash's official price page](https://help.aliyun.com/zh/model-studio/qwen3-7-flash) before running. On 2026-10-14, Beijing-region list prices per million tokens are still ¥0.2 input / ¥0.8 output up to 32K input per request, ¥0.6 / ¥2.4 at 32K–256K, and ¥1.2 / ¥4.8 above 256K. The arm configs convert these to USD at the [Bank of China](https://www.boc.cn/sourcedb/whpj/enindex_1619.html) middle rate published 2026-10-14 00:27:23, ¥6.7298/USD (中行折算价 672.98 per 100 USD). Because cache discounts are not assumed, Trace costs are **cache-miss upper bounds**, not invoice amounts. The runner requires this locked rate; to use new prices or a new rate, update both arms and create a new lock before any run. The ¥50 ceiling remains; each arm has a $0.20 task hard limit and a 64K/4096 per-call input/output cap. Even allowing one capped call beyond each hard limit, 24 planned paid trials are bounded to roughly ¥34 **under these price and token-limit assumptions**. The runner checks after each trial and keeps a one-trial reserve. Stop if assumptions fail; do not mark unrun tasks as failures.
4. Run `npm pack` from this repo and record the tarball SHA-256 plus code commit/diff hash in the run manifest. Keep that tarball and both arm config JSON files immutable for the batch. Provide `DASHSCOPE_API_KEY` to the Harbor process through its environment, never in the manifest.
5. Run `python scripts/harbor/run_subset.py smoke eval-artifacts/harbor/subset-lock-qwen-v2.json eval-artifacts/harbor/auto-talon-0.2.0.tgz 6.7298`; it checks Docker and Harbor, runs a one-task **oracle** check, then the first two locked tasks on both arms. Inspect Harbor's official reward and `autotalon-trial.json` with `costCoverage=1` for every paid trial. Any protocol, balance, installation, or official scoring failure invalidates that trial and stops the formal batch.
6. Run `python scripts/harbor/run_subset.py formal eval-artifacts/harbor/subset-lock-qwen-v2.json eval-artifacts/harbor/auto-talon-0.2.0.tgz 6.7298`. It runs all ten IDs on both arms, one at a time, records a conservative cost ledger, and stops if the ¥50 cap or one-trial reserve would be breached. It writes `comparison.json` with paired deltas and confidence intervals.

Example Harbor invocation for one locked ID (PowerShell; replace paths and version):

```powershell
harbor run -d 'terminal-bench/terminal-bench-2-1@VERSION' -a oracle -i 'TASK_ID' -n 1 -k 1
harbor run -d 'terminal-bench/terminal-bench-2-1@6' -a scripts.harbor.autotalon_agent:AutoTalonAgent -m 'qwen/qwen3.7-flash' --ak 'tarball_path=ABSOLUTE_TGZ' --ak 'arm_config_path=ABSOLUTE_ARM_JSON' --ak 'max_iterations=20' -i 'TASK_ID' -n 1 -k 1 -o 'eval-artifacts/harbor/jobs'
```

The example invocation is for debugging the Harbor adapter; use the runner above for the actual batch. Harbor's verifier reward is the success source; AutoTalon's trace supplies cost, rounds, tool calls, and failure diagnosis. Preserve Harbor's job directory and each `autotalon-trial.json`. Report both successes and failures. If both arms are near all-correct or all-wrong, label the subset insufficiently discriminating and design a new pre-registered subset.
